# 安全、Human Gate 与审计设计

文档状态：`DESIGN_ONLY`

实现状态：`NOT_IMPLEMENTED`

## 计划风险分级

- 自动区：计划仅允许只读解析、受控检索、确定性计算草案和候选方案生成。
- 人工复核区：计划覆盖低置信材料、证据冲突、规则不明确、参数争议和 Agent 分歧。
- Hard Gate：计划约束正式交付包、对外发送、签署、提交和企业系统写入。
- 禁止区：计划禁止删除或篡改证据、跨租户读取、Agent 模拟人工批准和未经授权的现实副作用。

## Human Gate 计划合同

计划中的 ApprovalRecord 需包含：

- `approval_request_id`；
- 审批对象引用与内容哈希；
- 证据、规则、计算和 AuditReport 摘要；
- 要求的审批角色；
- 批准、拒绝或退回决定；
- 审批人、理由、时间和签名或哈希；
- 有效范围、过期时间和被替代记录。

计划规则：

1. 不允许默认批准；
2. 不允许 Agent 模拟真实 Human 批准；
3. Audit Agent 不得批准自己的审计结果；
4. 审批超时、越权或审批对象变化时，旧批准计划失效；
5. 正式交付包计划仅接受有效且哈希一致的审批记录。

## 计划安全控制

| 风险 | 计划控制 |
|---|---|
| 文档提示注入 | 文档内容仅作为数据；系统指令和工具来源采用白名单 |
| 恶意文件 | 类型、大小和安全扫描；异常文件隔离 |
| 证据篡改 | 原始文件哈希、版本和只追加事件记录 |
| 规则过期／异地 | 地区与有效期过滤；无权威来源时弃答 |
| LLM 虚构计算 | 只允许确定性公式引擎输出金额 |
| 越权工具调用 | Identity 权限范围和网关消费方策略 |
| 跨租户读取 | `tenant_id` 强制过滤和命名空间隔离 |
| 密钥泄漏 | 密钥不进入 Agent、Prompt 或普通 Trace |
| 审批绕过 | 状态机、角色检查和审批对象哈希绑定 |
| 审批后篡改 | 相关产物变化后计划废止旧批准 |
| Trace 泄漏隐私 | 仅记录引用和脱敏摘要，限制访问和保留期限 |

## 回滚边界

计划支持的内部操作包括状态回退、Skill／公式／模板版本切换、生成物作废和可重试任务重放。

ProofFlow 不承诺撤销已经发送、签署或提交的现实动作。因此首版计划不自动执行这些不可逆动作。

以上控制当前均未完成攻防、权限或生产验证。

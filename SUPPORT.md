# Support

ProofFlow is an alpha, public-synthetic reference project. It has no production support or legal-advice SLA.

## Before opening an issue

1. Read the current status and limitations in [README.md](README.md).
2. Reproduce on the latest `main` or latest tagged alpha and record the full Git SHA.
3. Use only synthetic or legally shareable data.
4. Include the smallest command, expected result and actual stable error code.

Use a bug report for reproducible defects and a feature request for scoped product proposals. Questions about
real employment cases, personal data, production operations or emergency decisions are outside project
support.

Security vulnerabilities, secrets, tenant leaks, approval bypasses and exploit details must use
[private vulnerability reporting](https://github.com/MyGarfield/ProofFlow/security/advisories/new), not a public
issue.
